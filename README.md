# zenn-content

Articles published to [Zenn](https://zenn.dev/aligator527) through Zenn's GitHub integration.

## Why these are not copies

Each article starts as a note on [aligator527.github.io/notes](https://aligator527.github.io/notes/),
which is where the thinking is published first and in three languages. Zenn does not support an
external `canonical`, so a verbatim repost would put a second copy of the same text on a domain with
far more authority than mine — and the original would lose the search result it was written to win.

So an article here is a rewrite for a different reader: shorter paragraphs, code where the note has
prose, a checklist where the note has an argument, and a link to the original at the top for anyone
who wants the long version.

## Working on it

```bash
npm install
npm run preview   # http://localhost:8000
```

New article: `npx zenn new:article --slug some-slug`.
